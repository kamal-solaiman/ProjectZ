# استوديو المظهر — ProjectZ

## الوصول والسلوك

من القائمة الجانبية: **الاعدادات ← المظهر**. الشاشة جديدة ومربوطة فعليًا، وليست عنصر تحديد فقط.

- اختيار أي مظهر يطبّق **معاينة مباشرة** على النافذة الرئيسية والقائمة والشاشات والنوافذ المنبثقة وشاشة الدخول عبر موارد WPF مشتركة، دون إعادة إنشاء الشاشات أو فقد بيانات النماذج.
- **حفظ المظهر** يثبّت الاختيار والألوان محليًا. قبل الحفظ توجد شارة «معاينة غير محفوظة»، ويمكن إلغاء المعاينة بزر **استعادة المحفوظ**.
- عند إعادة التشغيل يُحمّل آخر ملف محفوظ **قبل إنشاء شاشة الدخول**، حتى لو كان SQL Server غير متصل.
- **الافتراضي** يعاين الزجاج الشفاف؛ يلزم الحفظ لاعتماده. **استعادة لوحة الافتراضية** داخل التصميم المخصص تعيد الأدوار اللونية الثمانية والعتامة والانحناءات الافتراضية.
- المطبوعات الورقية ومعاينات الفواتير/الإيصالات/الباركود معزولة بلوحة ألوان ثابتة، فلا يتغير حبر الطباعة أو تباين الباركود بتغيير المظهر.

## المظاهر التسعة

| المعرّف | المظهر | البصمة البصرية |
|---|---|---|
| `glassmorphism` | Glassmorphism — الزجاج الشفاف | أسطح نصف شفافة، حدود مضيئة، توهج ناعم وخلفية سماء هادئة |
| `liquid-glass` | Liquid Glass — الزجاج السائل | طبقات جليدية، لمعة لؤلؤية، حواف أكثر انحناءً وحركة خلفية بطيئة |
| `dark-glass` | Dark Glass — الزجاج الداكن | قاعدة ليلية، أسطح داكنة شفافة، نصوص فاتحة ولمسات فيروزية |
| `aurora` | Aurora UI — الشفق القطبي | أشرطة ضوء زمردية/بنفسجية فوق سماء ليلية مع حركة اختيارية هادئة |
| `holographic` | Holographic UI — الهولوجرافي | تدرج طيفي، حدود قزحية وخطوط مسح رقمية دقيقة |
| `fui` | FUI / HUD — الخيال العلمي | شبكة هندسية، زوايا حادة، أركان HUD وألوان رادار |
| `chrome` | Chrome / Liquid Metal | تدرجات فضية مصقولة وانعكاسات معدنية متعددة المراحل |
| `fluent` | Fluent Design — بروح Microsoft | أسطح محايدة، لمعة تفاعل، زوايا Windows هادئة ولمسة زرقاء |
| `custom` | تصميم مخصص | تحكم كامل في الأدوار اللونية الثمانية والعتامة والانحناءات |

الزجاج والانعكاسات تُركّب **داخل مساحة البرنامج** باستخدام WPF vectors/gradients. لا يوجد تعتيم لسطح المكتب خلف النافذة، ولا تأثير Mica/Acrylic الأصلي من النظام، ولا تشويش لكل محتوى حي؛ هذا مقصود للحفاظ على الأداء وتجنب خطافات نظام غير لازمة. حركة الخلفية في Aurora/Liquid فقط، وتحترم خيار «تقليل حركة الخلفية» وإعداد الحركة في Windows.

## التصميم المخصص

ثمانية أدوار: الخلفية، البطاقات/الأسطح، النص الأساسي، النص الثانوي، الأزرار/الإجراءات، الحدود/الفواصل، التمييز/التحديد، القائمة الجانبية.

- إدخال `#RRGGBB` مع تحقق فوري، أو منتقي ألوان بقنوات RGB وألوان سريعة ومعاينة نص متباينة.
- عتامة الأسطح من 35% إلى 100%، وانحناء الزوايا من 0 إلى 24 بكسل.
- فحص تباين WCAG sRGB بنسبة **4.5:1** للنصوص الأساسية. إذا اختار المستخدم نصًا غير مقروء، تعدّل الدرجة المستخدمة للعرض فقط لأقرب درجة تحقق النسبة؛ قيمة HEX المختارة تبقى محفوظة ويوضح التقرير أنها عُدّلت.
- لون نص الزر والقائمة يُختار تلقائيًا أبيض/داكن حسب الخلفية. ألوان الحالة (نجاح/خطأ/تحذير/معلومات) تشتق من المظهر مع الحفاظ على دلالتها.
- HEX غير المكتمل يمنع الحفظ ولا يستبدل آخر ملف جيد.

## الحفظ المحلي والاسترجاع

المسار الافتراضي لكل مستخدم Windows على الجهاز:

```text
%LOCALAPPDATA%\ProjectZ\appearance.json
%LOCALAPPDATA%\ProjectZ\appearance.json.bak
```

هذا اختيار **لكل جهاز/مستخدم Windows** وليس لكل حساب دخول داخل التطبيق، ولا يُكتب في `dbo.SystemSettings` ولا يدخل النسخ الاحتياطي SQL. الملف يحتوي إصدار المخطط، معرّف المظهر، اللوحة المخصصة، العتامة، الانحناءات وتقليل الحركة فقط؛ لا كلمات مرور أو بيانات محل أو إعدادات اتصال.

الحفظ ذري: كتابة ملف مؤقت مع flush إلى القرص، ثم `File.Replace` مع الاحتفاظ بالنسخة السابقة `.bak`. عند تلف الملف الأساسي يُقرأ الاحتياطي؛ وعند تلف الاثنين أو إصدار غير مدعوم يعود الزجاج الشفاف الافتراضي مع تحذير ظاهر في شاشة المظهر. فشل القرص لا يدّعي نجاحًا ولا يفقد المعاينة الحالية.

## البنية والملفات

- `Models/AppearanceModels.cs`: الكتالوج، الأدوار اللونية، التحقق وحسابات التباين.
- `Services/AppearanceStore.cs`: JSON المحلي، الحفظ الذري والاسترجاع.
- `Services/ThemeManager.cs`: تطبيق الموارد الحية، التدرجات، الشفافية، ألوان الحالة والخلفيات.
- `ViewModels/AppearanceViewModel.cs`: المعاينة/الحفظ/الاستعادة، محررات الألوان والتباين.
- `Views/AppearanceView.xaml`: شاشة الاستوديو العربية RTL.
- `Views/ColorPickerWindow.xaml`: منتقي الألوان.
- `Resources/ThemePalette.xaml` و`ThemeAliases.xaml`: مفاتيح الألوان والدلالات التي تربط ألوان الشاشات القديمة بالأدوار الجديدة.
- `Resources/ThemeBackdrop.xaml`: خلفيات vector مميزة لكل مظهر.
- `Resources/PrintIsolation.xaml`: عزل الطباعة عن المظهر.

الشاشات القديمة تستخدم `DynamicResource` بدل الألوان الثابتة. مفاتيح الإرث مقسمة حسب الدور (خلفية/نص/حد/حالة) حتى لا يتحول عنوان داكن إلى نص فاتح فوق بطاقة فاتحة بالخطأ.

## التحقق

أوامر Windows/.NET 10:

```powershell
python tools/static_checks.py
dotnet run --project tests/ProjectZ.Appearance.Tests -c Release
dotnet build ProjectZ.sln -c Release
```

اختبارات المظهر لا تحتاج WPF أو SQL وتغطي الكتالوج، التباين، الحفظ الذري، التلف/الاحتياطي، رفض القيم غير الصالحة، حالة المعاينة مقابل المحفوظ، وفشل القرص ثم إعادة المحاولة. بناء WPF وتشغيله بصريًا على Windows يظلان خطوة قبول مستقلة؛ بيئة Linux الحالية لا تشغّل WPF.
