# سجل القبول — لا يزال مفتوحًا

**الحالة: غير مكتمل.** لا يوجد SQL Server 2016 SP1 أو Windows في بيئة العمل الحالية. لم تُجرَ الاختبارات الفعلية أدناه ولم تُنتج نسخة EXE. يجب أن يسجل المنفذ التاريخ والأجهزة والإصدار الفعلي والنتيجة والدليل، دون أسرار، قبل اعتماد التسليم.

## فحوص البيئة الحالية

- مراجعة المصدر: يستخدم اتصال SqlClient مباشر وparameterized SELECT، ولا يوجد وسيط أو ORM.
- مراجعة SQL نصيًا: CREATE DATABASE/ALTER DATABASE وCREATE TABLE وIF وSYSUTCDATETIME وtransaction/locks جميعها من صياغة SQL 2016 أو أقدم. المستوى 130 محدد صراحة. ليست هذه شهادة تنفيذ فعلي.
- فحوص آلية محلية موثقة في `STATIC-CHECKS.txt`: JSON وXML وhash السكربت وتطابقه مع صيغة PBKDF2 وعدد الجداول المنشأة.
- اختبار C# في tests جاهز للتنفيذ، لكنه **لم يُشغّل** هنا؛ لا SDK.
- بناء Windows في workflow مُعد، لكنه **لم يُشغّل** هنا.

لإثبات اتصال الجهازين، ينفذ المسؤول على الخادم أثناء المحاولات (قد تبقى الاتصالات pooled):

```sql
SELECT s.host_name, s.program_name, s.login_name, DB_NAME(s.database_id) AS DatabaseName,
       c.client_net_address
FROM sys.dm_exec_sessions AS s
JOIN sys.dm_exec_connections AS c ON c.session_id = s.session_id
WHERE s.program_name = N'ProjectZ';
```
