# شاشة النسخ الاحتياطي والاسترجاع

## الغرض

هذه الصفحة مخصّصة لعمليتين اثنتين مربوطتين مباشرة بقاعدة بيانات SQL Server:

1. **أخذ نسخة احتياطية من قاعدة البيانات** (`BACKUP DATABASE`) إلى ملف `.bak` يختاره المستخدم.
2. **استرجاع نسخة احتياطية لقاعدة البيانات** (`RESTORE DATABASE`) من ملف `.bak` موجود، مع استبدال القاعدة الحالية ببيانات الملف.

الشاشة مدرجة في القائمة الجانبية ضمن فئة **الإعدادات** → بند **النسخ الاحتياطي** (الذي كان بندًا مخططًا له ولم يكن منفذًا)، وتفتح كأي شاشة أخرى من تطبيق ProjectZ عبر `MainViewModel`.

## كيف تعمل تقنيًا

- طبقة البيانات: `src/ProjectZ/Data/BackupRepository.cs` تستخدم `Microsoft.Data.SqlClient` وترسل أوامر T-SQL مباشرة إلى SQL Server:
  - النسخ: `BACKUP DATABASE [ProjectZ] TO DISK = @path WITH INIT, FORMAT, CHECKSUM` — ينشئ ملفًا جديدًا أو يستبدل ملفًا موجودًا بنفس الاسم، مع التحقق من سلامة الصفحات أثناء الكتابة.
  - الاسترجاع: يعزل القاعدة (`ALTER DATABASE ... SET SINGLE_USER WITH ROLLBACK IMMEDIATE`) لقطع الاتصالات النشطة، ثم ينفّذ `RESTORE DATABASE [ProjectZ] FROM DISK = @path WITH REPLACE, RECOVERY`، ثم يعيد القاعدة إلى وضع مستخدمين متعددين (`SET MULTI_USER`) حتى لو انتهت العملية بخطأ.
- مسار ملف النسخة يُتحقق منه من جانب العميل قبل الإرسال (.bak، ومجلد الوجهة موجود)، واسم القاعدة يُثبت من `connectionsettings.json` ولا يُقبل من المستخدم.
- تُقرأ حجم قاعدة البيانات وآخر نسخة مسجلة من `sys.database_files` و `msdb.dbo.backupset` للعرض في بطاقة معلومات القاعدة.
- جميع الرسائل والواجهة بالعربية (ar-EG)، وتollow pattern المشروع نفسه (MVVM مع `ObservableObject` و `AsyncCommand` وأشرطة الحالة).

## الصلاحيات المطلوبة على SQL Server

حساب الاتصال المستخدم في التطبيق (`ProjectZClient` في `connectionsettings.json`) يحتاج صلاحيات أعلى من صلاحيات القراءة/الكتابة العادية، لأن النسخ والاسترجاع عمليتين إداريين:

### على مستوى القاعدة (dbo.ProjectZ)

```sql
USE [ProjectZ];
GO
ALTER ROLE [db_owner] ADD MEMBER [ProjectZClient];
```

### على مستوى الخادم (لإنشاء/تعديل القاعدة عند الاسترجاع)

```sql
USE [master];
GO
ALTER SERVER ROLE [dbcreator] ADD MEMBER [ProjectZClient];
```

بدون هذه الصلاحيات، تظهر رسالة عربية توضح المشكلة وأرقام أخطاء SQL الشائعة (229/230 نقص صلاحية، 18456 فشل تسجيل الدخول، 2 و53 مشاكل الاتصال، 3159 القاعدة مستخدمة من مستخدمين آخرين...).

> ملاحظة: إذا كانت السياسة الأمنية禁止 استخدام `db_owner`، يمكن منح الصلاحيات granular بدلاً من ذلك: `BACKUP DATABASE`, `BACKUP LOG` على القاعدة، و `CREATE ANY DATABASE` و `ALTER ANY DATABASE` على الخادم، مع `ALTER` على قاعدة ProjectZ لإنجاز وضع SINGLE_USER/MULTI_USER.

## تشغيل الشاشة

1. سجّل الدخول إلى ProjectZ بحساب لديه اتصال بقاعدة البيانات (تظهر شارة «متصل بقاعدة البيانات»).
2. من القائمة الجانبية (فئة الإعدادات) اختر **النسخ الاحتياطي**.
3. **لأخذ نسخة**: اختر مجلد الحفظ، اكتب اسم الملف (افتراضيًا `ProjectZ_yyyyMMdd_HHmmss.bak`)، ثم اضغط **«أخذ النسخة الاحتياطية»**. يُحفظ الملف مع استبدال أي ملف موجود بنفس الاسم.
4. **لاسترجاع نسخة**: اختر ملف `.bak` من خلال استعراض الملفات، ثم اضغط **«استرجاع النسخة الاحتياطية المحددة»** بعد التأكيد. تحذير: الاسترجاع يستبدل القاعدة الحالية بالكامل ويفقد أي بيانات أُضيفت بعد تاريخ النسخة المختارة.
5. تظهر أشرطة الحالة بنتيجة كل عملية (نجاح/فشل) معreason العربي عند الخطأ.

## توصيات تشغيلية

- جدولة نسخ احتياطي منتظم (يوميًا على الأقل) وحفظ الملفات على قرص خارجي أو خادم نسخ احتياطي منفصل، ليس على قرص قاعدة البيانات نفسها فقط.
- اختبار استرجاع نسخة على قاعدة تجريبية دوريًا للتأكد من سلامة الملفات.
- قبل الاسترجاع، تأكد من إغلاق جميع شاشات ProjectZ التي تستخدم القاعدة على أي جهاز، لأن الاسترجاع يقطع الاتصالات النشطة وقد يفشل لو بقيت القاعدة مشغولة.
- لا يُنصح بالاسترجاع خلال أوقات الذروة التشغيلية.

## ملفات المشروع المتأثرة

| الملف | الدور |
|------|------|
| `src/ProjectZ/Data/BackupRepository.cs` | طبقة البيانات: أوامر النسخ والاسترجاع على SQL Server |
| `src/ProjectZ/ViewModels/BackupViewModel.cs` | منطق الشاشة والتحقق والرسائل بالعربية |
| `src/ProjectZ/Views/BackupView.xaml` | واجهة المستخدم (RTL، عربية) |
| `src/ProjectZ/Views/BackupView.xaml.cs` | فتح مربعات اختيار المجلد والملف ونافذة التأكيد |
| `src/ProjectZ/ViewModels/MainViewModel.cs` | تسجيل الشاشة في القائمة الجانبية (`الاعدادات → النسخ الاحتياطي`) |
| `src/ProjectZ/Views/MainWindow.xaml` | استضافة عرض الشاشة عبر DataTrigger |
| `src/ProjectZ/App.xaml.cs` | إنشاء `BackupRepository` وتمريره لشكل main |

## ملاحظات القبول

لا يمكن تشغيل WPF أو SQL Server داخل بيئة الفحص النصي الحالية؛ التحقق من 동작 الشاشة يتطلب كمبيوتر Windows عليه SQL Server 2016 SP1 أو أحدث وقاعدة `ProjectZ` مبنية عبر السكربتات في مجلد `sql/` وصلاحيات الحساب موضحة أعلاه.
