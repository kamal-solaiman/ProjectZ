# دليل تشغيل أجهزة العملاء (LAN Clients)

## 1. المتطلبات على جهاز العميل
- نظام Windows 10/11.
- لا يحتاج الجهاز إلى تثبيت Visual Studio.
- لا يحتاج الجهاز إلى تثبيت .NET Runtime (النسخة المنشورة Self-Contained تحتوي على الـ Runtime بداخلها).
- لا يحتاج الجهاز إلى تثبيت SQL Server — قاعدة البيانات موجودة على الجهاز الرئيسي فقط.

## 2. نسخ البرنامج
1. من مجلد النشر `FitohPhone/bin/Release/net10.0-windows/win-x64/publish` انسخ الملفات التالية إلى أي مجلد على جهاز العميل:
   - `FitohPhone.exe`
   - `appsettings.json`
2. شغّل `FitohPhone.exe`.

## 3. التحقق من الاتصال قبل التشغيل
تأكد أن جهاز العميل يصل إلى الجهاز الرئيسي:
```powershell
ping MAIN-PC-NAME
Test-NetConnection -ComputerName MAIN-PC-NAME -Port 1433
```
(استبدل MAIN-PC-NAME باسم الجهاز الرئيسي أو استخدم عنوان IP مثل 192.168.1.10)

## 4. التعامل مع انقطاع الاتصال
إذا تعذر الاتصال بقاعدة البيانات (السيرفر الرئيسي مغلق أو الشبكة مقطوعة)، يظهر البرنامج رسالة خطأ واضحة:
> "تعذر الاتصال بقاعدة البيانات. تأكد من أن السيرفر الرئيسي يعمل وأن عنوان السيرفر صحيح في ملف appsettings.json."

## 5. نفس البيانات على جميع الأجهزة
جميع أجهزة العملاء تتصل بنفس قاعدة البيانات `FitohPhone` على الجهاز الرئيسي، نفس المستخدمين وكلمات المرور تعمل من أي جهاز.
